Privacy Policy

Last updated: August 20, 2024

1. Overview

Eclipse is a Discord moderation bot that operates within Discord servers. This Privacy Policy explains what information Eclipse processes, how it is used, and how it is stored.

2. Information Processed

Eclipse processes the following information to provide its features:

2.1 Discord User Information

  • User IDs (for identification in moderation cases and configuration)
  • User display names and nicknames (for AFK system and display purposes)
  • Member roles (for permission checks and jail system role preservation)

2.2 Server Information

  • Guild (server) IDs (for per-server configuration)
  • Channel IDs (for log channels and jail channels)
  • Role IDs (for moderator roles, administrator roles, and jail roles)

2.3 Message Content

When automated moderation is enabled, Eclipse processes message content in real-time to detect:

  • Spam messages
  • Duplicate messages
  • Excessive mentions
  • Blocked words or terms
  • Disallowed links or invites

Message content is not stored or persisted. It is only analyzed in real-time and then discarded.

3. Information Stored

Eclipse stores information in a local SQLite database on the server where it is hosted:

Data Type What is Stored Purpose
Moderation Cases User IDs, moderator IDs, action taken, reason, timestamp, status Audit trail for moderation actions
Guild Configuration Server settings (thresholds, roles, channels, blocked terms) Per-server customization
AFK State User ID, original nickname, AFK message, timestamp AFK system functionality
Jail Metadata Previous role IDs (stored in case metadata) Role restoration when unjailing

3.1 What is NOT Stored

  • Message content (processed in real-time only)
  • User email addresses
  • IP addresses
  • Private tokens or credentials
  • User personal information beyond Discord IDs

4. How Information is Used

Eclipse uses the stored information solely to:

  • Execute moderation commands issued by authorized moderators
  • Apply automated moderation rules configured by server administrators
  • Maintain an audit trail of moderation actions
  • Provide per-server configuration and customization
  • Manage the AFK and jail systems

5. Discord's Role

Eclipse operates through Discord's API and is subject to Discord's Terms of Service and Privacy Policy. Discord provides the platform and handles its own data collection and processing.

6. Third-Party Services

Eclipse does not transmit data to any third parties beyond Discord. All data processing and storage occurs on the local server where Eclipse is hosted.

7. Data Retention

Data is retained as follows:

  • Moderation cases: Retained indefinitely until manually deleted by server administrators
  • Guild configuration: Retained while Eclipse is in the server
  • AFK state: Cleared when a user sends a message or when they are manually removed from AFK state

There is no automatic data deletion mechanism. Data persists until the bot is removed from the server or the database is manually cleared by the server host.

8. Data Deletion

To remove data associated with your server:

  • Remove Eclipse from your Discord server
  • Contact the server host to delete the Eclipse database file

Eclipse does not provide a user-facing data deletion mechanism. Server administrators control the database and can delete it at any time.

9. Security Practices

Eclipse implements the following security measures:

  • Bot tokens and credentials are stored in environment variables, never in code
  • The .env file containing sensitive configuration is excluded from version control
  • Database access is local only (no remote database connections)
  • Input validation is performed on all configuration values
  • SQL queries use parameterized statements to prevent injection attacks

10. Children's Privacy

Eclipse does not knowingly collect personal information from children under 13. As a Discord bot, Eclipse operates within Discord's platform, which itself requires users to be at least 13 years old (or the minimum age in their country). Eclipse does not collect any information beyond what is necessary for its moderation functionality.

11. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be reflected by the "Last updated" date at the top of this page.
