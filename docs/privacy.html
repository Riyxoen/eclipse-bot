Privacy Policy

Last updated: October 30, 2026

1. Who We Are

Moon is a Discord moderation bot operated by Riyxo. This Privacy Policy explains how Moon handles information when it is added to or used in a Discord server.

2. Information We Process

We process only the information needed to provide moderation, server-configuration, AFK, custom-role, and jail features.

Discord and server information

  • Guild, channel, role, and user IDs.
  • Member display names and nicknames when needed for AFK status and command responses.
  • Member roles for permission checks, moderation safeguards, and role restoration.
  • Member-join timestamps for optional raid protection.

Messages and commands

Moon reads message content when message-content access is enabled to run prefix commands and, when a server enables automated moderation, to check spam, duplicate messages, mentions, blocked terms, links, and Discord invites. Moderation-command and AFK reasons supplied to Moon may be stored as described below.

Raw message content is not stored in Moon's database. For duplicate-message detection, a normalized copy of recent message text is kept only in memory for the configured detection window, then discarded. This temporary memory is not retained after a restart.

3. Information We Store

Moon uses a local SQLite database on the server where it is hosted. Depending on enabled features, it stores:

Data typeWhat is storedPurpose
Moderation casesGuild, target-user, and moderator IDs; action; reason; time; duration or expiry; result; automated-detector label; and limited action metadata.Audit trail, moderation history, warnings, and reversible actions.
ConfigurationServer settings, including thresholds, role and channel IDs, prefixes, exemptions, blocked terms, allowed domains or invite codes, and the ID and time of the latest configuration change.Per-server configuration.
AFK stateUser ID, original name or nickname, AFK message, and time set.AFK status and nickname restoration.
Action metadataOnly data required to reverse or report an action, such as prior role IDs, channel-permission state, restored-role count, or DM-delivery status.Jail, channel-lock, and notification functionality.

If the operator enables file logging, local logs may also contain operational metadata such as IDs, command names, timestamps, and errors. Moon redacts configured secrets and token-shaped values from its logs.

Moon does not store user email addresses, IP addresses, Discord passwords, bot tokens, or raw message content in its database.

4. How We Use and Share Information

We use this information to provide the features above, apply moderation and configured automated rules, maintain a moderation record, restore AFK or jail state, and keep the service secure and reliable.

Moon operates through Discord's API. Case summaries may be posted to a server's configured moderation-log channel, and moderation notifications may be sent by Discord direct message when that feature is enabled. Moon does not sell data or send it to analytics, advertising, or other third-party services. Discord processes information under its own Privacy Policy.

5. Retention and Deletion

AFK state is removed when the user becomes active again or is manually removed from AFK. Configuration and moderation cases are retained until the database host deletes them, the data is no longer needed for the bot's operation, or a valid deletion request requires their removal. Removing Moon from a server does not by itself delete existing local records.

To request access to, correction of, or deletion of data associated with you or your server, contact us through the Moon support server. Include your Discord user ID or server ID and enough information for us to identify the request. We may need to verify that you control the relevant account or server before acting on a request.

6. Security

Moon uses environment variables for credentials, redacts secrets from its application logs, validates configuration input, and uses parameterized SQL queries. The database is local to the host running Moon; the host operator is responsible for securing that host, its database file, backups, and access controls.

7. Children and Changes

Moon is intended for use through Discord, whose services have their own minimum-age requirements. We do not knowingly use Moon to collect information from children in violation of applicable law.

We may update this policy when Moon or its data practices change. The updated version will be posted here with a new “Last updated” date.

8. Contact

For privacy questions or requests, contact us through the Moon support server or open a private support request. For source-code issues, use GitHub Issues; do not post personal data there.
