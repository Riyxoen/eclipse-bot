2. What Eclipse Does

Eclipse is a Discord moderation bot that helps server administrators manage their communities. It provides:

  • Manual moderation commands (warn, mute, kick, ban)
  • Automated moderation (spam, duplicate, mention, and word filter detection)
  • Server configuration tools
  • Logging and case tracking
  • Custom role management
  • AFK system
  • Jail system
